# A first local achievement

No account or backend is needed. With Node.js 24 installed:

```sh
npm ci
npm run dev
```

Complete three lessons using the button to unlock an achievement. Replace `src/App.tsx` with any complete export from the [playground](https://github.com/dave-b-b/achievements-starter) to try your own configuration.

```sh
npm run build
```

The example uses published React Achievements 6.0.0 and Engine 2.1.0 releases. For server-authoritative saved progress, use the full starter and its [setup guide](../../docs/setup.md).
